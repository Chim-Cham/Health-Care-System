# Health-Care-System
Group Assignment, Goal to develeop a system to handle patients and administrate doctors.

Welcome to our Health care system 

to start program you need to clone the repository and run with the command: dotnet run

When starting the program you get the inital menu for the first options (Log in, Register or quit) 1-3.
when you have logged in the menu will look different depending on the logged in user.
Patients menu will have one design, staff and admins will have differnet menu designs. 

to navigate in these menus you have to use the number keys and then press enter. 

In some cases for admins you have a menu inside the menu that use the same way to navigate but when the program lists users,
you need to type the name of the wished user to interact with. 
____________________________________________________________________________________________________________________________

The code structure we have used is interfaces with three different classes of users and have given every file the method that is used,
in the correspond users menu. 
in program.cs we call the user-specific menus that are all methods. In the specific menus we follow the same structure with calling methods
and all those methods are in the same file, for instance all methods concerning an admin user is in admin.cs.
